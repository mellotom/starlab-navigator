# starlab-navigator

travelers guide for deep space exploration: a one-page reference for the **strymon starlab** time-warped reverberator. textures, size and pitch, delay and karplus-strong string mode, shimmer and glimmer, filter, lfo, pitch quantize scales, favorites, cv inputs and power-up options, with diagrams.

source: the [strymon starlab user manual, rev a](https://www.strymon.net/support/starlab/).

part of the [travelers guide welcome center](https://mellotom.github.io/travelers-guide/).

not affiliated with strymon.
